# Family Memory Flywheel - an opt-in lifecycle, not passive monitoring

## Four checkpoints
1. **Remember** - one authorized source or user-told memory. Capture specific facts with provenance; never equate a visual clue with the meaning of the memory.
2. **Care** - the user chooses a proposed Moment Card with one personalized action; no purchase, invitations, calendar, notification or automation.
3. **Live** - real people act **outside** the Skill. The Skill must not claim the plan happened; it awaits a voluntary return.
4. **Reflect and preserve** - user reports what happened; optional fresh, approved media may support it. Draft a new chapter with `LIVED` status only after confirmation, and save as a separately approved new text file. The previous intention stays unchanged.

## Why it could become a frequent habit
The product is relevant whenever a person asks “How do I make this matter?”; it does not need a daily push. High-frequency opportunities include thank-you gestures, welcoming someone home, first-day encouragement, small weekend rituals, meeting parents after a long gap, and milestone occasions. The experience must fit a 30-second prompt, with optional deeper NAS discovery. Avoid forcing a big emotional project for every ordinary task.

## Success measures for a future product study, not measured claims
- `time_to_first_useful_option`: minutes/turns to a meaningful actionable suggestion.
- `meaning_confirmation_rate`: proportion of proposed bridges accepted or corrected by the user, not classifier confidence.
- `choice_or_adaptation_rate`: whether a user voluntarily chooses or modifies an option.
- `story_integrity_rate`: claims with evidence labels and no unsupported emotional inference.
- `saved_with_approval_rate`: verified writes with user review and platform workflow approval.
- `return_and_reflect_rate`: voluntary later returns, not system-triggered reminders.
- Qualitative outcome: did the real recipient feel considered? Ask only when voluntarily reported; never assume from actions.

## Runtime boundary
No built-in durable user profile, invisible progress tracker, notification system, background engine, autonomous family monitoring or persistent graph is claimed. If a previously saved Moment Card cannot be retrieved by an exact authorized path, ask the user to select/paste it; do not invent memory of an earlier session. The value flywheel is a **designed user journey** supported by separately approved text artifacts, not an automatic data pipeline.
