# Guided initiation and optional future invitation

## For past or present story reconstruction

Ask no more than three high-information questions **together**, based only on actually returned authorized source clues, and allow one free-form answer:

1. **Life anchors:** "How do these places or periods fit into your life, and what changed between them?" If nothing source-grounded is visible, ask an open question without supplying invented years/places.
2. **People and relationships:** "Who are the important people in these memories, and how are they connected to you?" Never infer identity from visual resemblance.
3. **Meaning:** "What mattered about this moment that a photo or document couldn't show?"

A user may skip any item. Attach answers as `USER_TESTIMONY` and show cross-source matches for confirmation. No permanent storage of raw narrative is implied. If the user has already shared equivalent context, do not repeat questions.

## Optional bridge to a meaningful future (only after user interest)

After a reviewed past/present memory, ask only once: **"Does this memory inspire something you'd like to revisit, finish, carry forward, or create differently?"** Offer no regret diagnosis. If user declines, preserve the memory only. If they accept, use [future_chapter.md](future_chapter.md) and the Purpose Check.

## Future-only start (archives not required)

A personally told past moment or lesson is still required as an *anchor*, but NAS file discovery is optional. Ask up to three grouped prompts: **"Which memory or experience inspires this? What makes it important to you now? What new experience would you want to live?"** Accept one unstructured answer. Do not invent unmet needs, ask for exact deadlines, or promise outcomes. If user wants future ideas without an anchor, invite a brief personally relevant memory, or make an unfinished sketch explicitly lacking the link.
