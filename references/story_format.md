# Story and life-chapter output formats

## A. Past / Present chapter

- **Title:** user-approved, neutral unless the emotional description is sourced
- **Lens:** person, period, event, place, theme or present moment
- **Scope & coverage:** exact authorized source sets and `PARTIAL_COVERAGE` if incomplete
- **Context:** short paragraph citing actually returned source IDs/paths and precision
- **The story:** up to five short paragraphs, weaving only evidence and attributed user recollection; no fabricated dialogue, motives or family relationships
- **Evidence gallery:** returned photo IDs/paths, document passages, audio transcript reference if used
- **Unknowns and conflicts:** at most three gentle open questions; contradictory claims shown without an invented resolution
- **Correction note:** what changed following user review
- **Proposed new file:** title, approved audience/path, user content review status

## B. Future / Unwritten chapter

Follow [future_chapter.md](future_chapter.md): a present-day **intention** that explicitly says `UNWRITTEN`, with a user-confirmed memory anchor (from authorized source or personal testimony), personally expressed meaning bridge, optional purpose lens, chosen future experience and blank lived-experience section. NAS files are optional; personally meaningful grounding is not. Save an approved intention without implying future prediction, delivery, automatic updates or access locks.

## C. Return-to-future account

Side by side: "What I hoped for" (preserved user intention) and "What actually happened" (new user testimony plus optional selected current sources). Never score the user, invent outcomes or modify the original saved wish. A separately approved new text version is required.

## D. Occasion / everyday care chapter

- **Occasion / recipient:** Only user supplied or separately authorized; do not infer birthdays, age or relationship from media.
- **Meaning anchor:** User-confirmed memory, cited selected source, or explicitly `No personal anchor supplied - general idea`.
- **What could make this feel personal:** Attributed preference or user hope; never a psychological inference.
- **Ideas:** Two or three distinct options with why it may fit, small steps, low-effort alternative and voluntary participants.
- **Status:** `SUGGESTED` or `PLANNED`, never `COMPLETED` until an actual user report.
- **Consent and constraints:** Budget, audience, access, invitation and any caveats as supplied; no booking/purchase/messaging.
- **Afterwards:** Blank until user returns; optional `LIVED` record is separate and approval-gated.

See [everyday_care.md](everyday_care.md) for examples and fast entry.
